# APN permutations in even dimension: code and data

Code, generated data and expected results of the paper

> E. Bellini, *On the search for APN permutations in even dimension: exact switching and a fast
> test for CCZ-equivalence to permutations*, submitted to Cryptography and Communications.

Every number reported in the paper can be regenerated by the scripts in `experiments/` and is
checked by `verify.py`. The Python package is called `apnsearch`.

## Requirements

- Python 3.10 or later with NumPy (`pip install -r requirements.txt`)
- a C compiler (`cc`), and `c++` and `git` for experiment E8
- the C core is compiled automatically on first import into `~/.cache/apnsearch`
  (override with `APNSEARCH_BUILD=<dir>`)

Tested on macOS 26 (Apple clang 16, Python 3.13, NumPy 2.4). The tree-search campaign of
E8 was run on Ubuntu 22.04 (gcc 11.4, Python 3.10, NumPy 1.24).

## Quick start

```sh
python3 -m pytest tests -q      # unit tests, a few seconds
./run_all.sh --quick            # E1-E7, E9 and E11 with reduced budgets, then verify.py (~30 min)
./run_all.sh                    # full budgets (a few hours on 18 cores)
python3 verify.py               # check the numbers of the paper against results/*.json
```

The `results/` directory already contains the output of the full runs used in the paper, so
`python3 verify.py` can be run immediately.

## Layout

| Path | Content |
|---|---|
| `apnsearch/_fast.c`, `fast.py` | C core and bindings: cost function, incremental local search, vector space search, switching kernels, bilinear-form search, APN test from the bilinear matrix |
| `apnsearch/gf.py` | arithmetic in GF(2^n), n <= 12, polynomial basis (primitive moduli in `PRIMITIVE`) |
| `apnsearch/ccz.py` | CCZ-equivalence to a permutation: exhaustive test and the dual test (Algorithm 1, Theorem 8), with the Walsh-free variant for quadratic functions (`quadratic=True`) |
| `apnsearch/equivalence.py` | explicit EA-equivalence of quadratic APN functions (search through the ortho-derivatives, with an independent check of the certificate) |
| `apnsearch/switching.py` | exact switching and exploration of switching neighbourhoods (Section 5) |
| `apnsearch/invariants.py` | ortho-derivative spectra, algebraic degree |
| `apnsearch/families.py` | known APN functions used in the experiments (power functions, Kim, Edel-Pott, F3/F4/F12/F13 in dimension 10, Beierle-Leander data, and the further dimension-10 sources of E11) |
| `experiments/e0*.py` | one script per experiment, writing `results/<name>.json` |
| `data/` | `n10_known_classes.json` (written by E4); `apn_10bit.txt` (downloaded from Zenodo by E4) |
| `results/` | results of the full runs; `e08_raw/` contains the tree-search solutions |

### E8: tree search

The tree-search code of Beierle and Leander (GPL-3.0, Zenodo 10.5281/zenodo.4305864) is not
redistributed here; `build` clones it into `external/` and compiles it.

```sh
cd experiments
python3 e08_tree_search.py build
python3 e08_tree_search.py sweep --seconds 300            # deterministic search, 195 classes
python3 e08_tree_search.py campaign --workers 128 --hours 24
python3 e08_tree_search.py collect                        # classify and CCZ-test all solutions
```

`touch STOP` in the repository root stops a running campaign after the current slices.

## Conventions

- Vectors of F_2^n are integers; GF(2^n) elements use the polynomial basis modulo
  `gf.PRIMITIVE[n]`, and alpha = 2 is primitive.
- Walsh space vectors are packed as `(a << n) | b`, with `W_F(a, b) = sum_x (-1)^(a.x + b.F(x))`.
- `cost(F)` is `sum_{a != 0, b} C(delta_F(a, b)/2, 2)`, which is 0 exactly for APN functions and
  equals 3 times the number of 2-flats on which F is affine (Lemma 2).
- Classes of quadratic APN functions are told apart by the spectra of the ortho-derivative.
  This invariant is not complete; the CCZ tests in E4 and E8 are therefore applied to every
  distinct function, not only to one representative per class.
